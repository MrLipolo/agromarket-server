## Тестирование
1. Создать базу `agromarket_test`
2. Настроить `.env.test`
3. Запуск тестов: `npm test`, просмотр покрытия: `npm run coverage`

## Лабораторная 8 — ответы
- Какие тесты упали, когда убрали adminOnly: упали тесты проверки 403 Forbidden в access.test.js, так как метод стал доступен без прав админа.
- Покрытие (Lines): 68.14%. Непокрытые строки в orders.js связаны с отсутствием тестов оформления заказов.
- Чем unit-тест отличается от интеграционного: unit-тест проверяет отдельную функцию изолированно с помощью mock-объектов (без БД), а интеграционный — цепочку HTTP -> Express -> БД.

## Безопасность
- Helmet добавляет защитные HTTP-заголовки и отключает `X-Powered-By`.
- CORS разрешает origin из `CORS_ORIGINS` (список через запятую); по умолчанию — `http://localhost:5173`. На Render задайте точный адрес фронтенда.
- Ограничение для `/api/auth/login` и `/api/auth/register`: 10 запросов с IP за 15 минут; в тестовом режиме отключено. `trust proxy = 1` учитывает IP клиента за прокси Render.
- Zod проверяет регистрацию, вход, создание/обновление товара; ID товара проверяется до запроса к БД. JSON-тело ограничено 100 КБ.

## Лабораторная 11 — локальные результаты
- Аудит `npm audit --omit=dev`: 0 уязвимостей на момент проверки.
- Файл `.env.example` отслеживается Git; локальные `.env` исключены правилами Git. В истории встречаются имена переменных и тестовые/примерные значения. Проверьте историю приватно и при обнаружении действующих секретов немедленно смените их.
- До добавления Zod роль не передавалась в SQL при регистрации, поэтому поле `role: admin` не создавало администратора. Это подтверждают текущий SQL и тест `auth.test.js`.
- React-валидации недостаточно, так как HTTP-запрос можно отправить напрямую. Серверная схема проверяет данные независимо от формы и удаляет неизвестные поля.
- `trust proxy` нужен, чтобы лимитер видел IP клиента за Render; без него запросы могут учитываться как пришедшие от одного прокси.
- Облачный деплой, GitHub Release и время Instant Rollback не проверялись локально; заполнить время отката после демонстрации: ___ с. После Instant Rollback нужен `git revert`, чтобы исправленный код в Git соответствовал production.
- Для публикации задайте `CORS_ORIGINS` в Render и проведите деплой вручную после ревью.
- ИИ использован для внесения изменений и подготовки тестов лабораторной.
